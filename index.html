? How to use the timetable

A quick tour of everything you can do on this page.

📂 Loading a CSV

On the upload screen, click Choose CSV file or drag & drop a TimeEdit CSV export onto the dashed box.

To replace the current data at any time, open the Settings panel (bottom-right ⚙️) and click Load another CSV.

🔍 Searching

Click the magnifier in the bottom-left corner to slide out the search field.

Matching events are highlighted with a yellow glow and gently jiggle. Search covers module code, module name, event title, event type, staff names and week numbers.

Press Esc to clear the search and collapse the box.

ℹ Viewing event details

Click any coloured block in the timetable to open a details popup next to it.

The popup shows module code, module name, title, type, day, time, weeks, duration, and staff. If the event extends beyond the visible time range it will still show its true start and end times.

Close the popup with the × button, by clicking outside it, or with Esc.

✎ Editing an event

In the details popup for a non-combined event you can edit the title, module code and event type directly.

Click the field, change the text, and press Enter or click elsewhere to commit. The block on the timetable updates immediately, and the highlighted-titles list in Settings is updated to reflect any new titles.

Editing is disabled for combined events — break them apart first if you need to change their parts.

🔗 Combining events

Drag one event on top of another event to combine them into a single block. Combining is allowed only when both events are on the same day, start at the same time, and have the same duration.

While dragging, the target turns green if compatible, or red if not. Dropping on an incompatible target shows a short error message.

When events combine:

  • Identical fields are kept once.
  • Different fields are joined with commas.
  • Week numbers are merged (e.g. 1,2,3 → 1-3).

You can combine more than two events by dragging a combined event onto another, or onto a normal one.

⇄ Moving events between columns

If an event's cell overlaps other cells, its day is split into columns so each overlaps visually. You can drag a cell to a different column.

  • Dropping a cell on another cell always attempts a combine (see above).
  • Dropping a cell on empty space moves it to that column and cascades any overlapping cells out of the way.
  • Dropping on a column in a different weekday moves the cell to the leftmost column of its own weekday (if dropping leftward) or the rightmost column (if dropping rightward).
  • Dragging is disabled for cells in single-column days.

Cascade: when a cell moves from column i to column j, any cell that overlaps it in time and sits between the two columns is pushed one column in the opposite direction. Those pushed cells then push whatever overlaps them, and so on. For example, on a Monday with X 9–11 in column 1 and Y 9–10 and Z 10–11 in column 2, dragging Y onto column 1 pushes X into column 2, which in turn pushes Z back into column 1.

✂ Breaking a combined event apart

Open the details popup for a combined event. A yellow 🔗 Combined pill indicates how many parts it contains.

Click Break apart into N parts to restore every constituent event individually — even if it was built up from several combine operations.

🗑 Deleting an event

Open the details popup and click 🗑️ Delete to remove the event from the timetable.

Deleting a combined event removes the whole combined block, not just one part. This action cannot be undone — reload the CSV to restore it.

⚙️ Settings

Click the gear in the bottom-right corner to open the Settings panel.

  • Visible time range — set the earliest and latest hours shown on the timetable. Events outside the range are clipped to the edges; their true times still appear in the details popup.
  • Week 1 — pick the week that should count as Week 1 using the calendar picker. The calendar runs Sunday–Saturday; picking any day in a row makes the Mon–Fri of that row Week 1. On first CSV load, Week 1 is auto-set to the earliest event's week; picking a week manually overrides this.
  • Highlight event titles — tick any titles to give matching cells a violet left border. Each title is treated separately, so a combined event is highlighted if any of its parts has a ticked title.
  • Load another CSV — replace the current data with a fresh file.
  • Help — reopen this guide.

The default range is 9:00–18:00. When a CSV is loaded, if any event starts earlier or ends later, the range is automatically widened to the nearest whole hour.

📄 Creating a PDF

Before printing to a PDF, it may help to combine events of the same type to reduce the number of columns. Making the text on the page smaller (by reducing the magnification) or printing to a larger PDF paper size (e.g. A3) may help.
